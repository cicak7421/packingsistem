Import Pesanan

Upload file export "Export Order Package" dari marketplace untuk ditambahkan ke sistem. Toko & platform terbaca otomatis dari file. Pesanan Advance Fulfilment diimport dari PDF batch resinya (kartu di bawah).

Advance Fulfilment PDF batch resi

Upload PDF batch resi Advance Fulfilment (satu halaman = satu resi). No. pesanan, no. resi, SKU, alamat, penerima, dan pengirim dibaca otomatis dari resi. Harga diisi "-" karena gak ada di resi. Hasil bacaan dicek dulu sebelum disimpan.

Gak ada file export?

Estimasi Penghasilan

Perkiraan penghasilan dari pesanan, direkap per hari dan per bulan berdasarkan waktu pesanan dibuat (kalau kosong, dipakai tanggal import pertama). Pesanan yang masuk setelah jam 22:30 WIB dihitung ke hari berikutnya. Pesanan Advance Fulfilment (tanpa harga di resi) dihitung otomatis dari harga per SKU lalu dikurangi potongan (diatur di menu Konfigurasi Harga); pesanan affiliate tidak dihitung.
